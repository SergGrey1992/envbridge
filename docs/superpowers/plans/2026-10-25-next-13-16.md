# Next.js 13–16: план совместимости

Цель: одинаковое подключение App Router и реальная совместимость с React 18/19 без withRuntimeEnv.

## Архитектура
Рекомендуется Node Route Handler `/__runtime-env` с `dynamic = 'force-dynamic'`, GET/HEAD через новый createRuntimeEnvHandler(config). RuntimeEnvScript остаётся в head, root layout использует force-dynamic (connection не требуется). Старый createRuntimeEnvProxy сохраняется для Next16, но не рекомендуется для Edge middleware старых версий. Клиентский snapshot и sync XHR fallback для global-error остаются прежними.

Middleware на Next13/14 использует Edge и не является надёжной единой точкой runtime-чтения. Route Handler одинаково поддерживается всеми целевыми ветками и устраняет эту зависимость. Ключи public/server и API getters не меняются.

## Задачи
- [x] RED→GREEN тесты handler: allowlist, динамическое чтение, undefined/null, HEAD, запрет POST, отсутствие CORS, no-store.
- [x] Реализовать handler и делегирование proxy, убрать connection/proxy из основного примера, использовать force-dynamic и next.config.mjs.
- [x] Независимые consumers с tarball: Next13.5.11 + React18.3.1; Next14.2.35 + React18.3.1; Next15.5.28 + React19.2.7; Next16.2.9 и16.4.3 + React19.2.7. Никаких force/legacy-peer-deps.
- [x] Каждая версия: strict generated types, production/standalone A/B из одной сборки, SSR/hydration, NEXT_PUBLIC, отсутствующие значения, 404/notFound, segment/global error и recovery, streaming, secret scan, server-only negative build.
- [x] Расширить peers только после успешных прогонов. Добавить матрицу CI и документацию минимальных patch-версий, React, Node, ограничений.
- [x] Финальные проверки, независимое ревью, коммит и push в разрешённый отдельный репозиторий.

Решения: поддерживаем App Router начиная с последнего patch ветки13.5, не экспериментальные13.0–13.3 и не Pages Router. Node>=22.18 сохраняется, младшие Node не заявляются. Выбранные patch-версии проверены через npm registry. Локальные данные .idea не изменяются и не коммитятся.

Итог: все5 строк матрицы прошли полный цикл (20 browser прогонов +5 negative builds). npm run check:46 тестов, формат/lint/typecheck/build PASS. Docker: один image, два окружения PASS. Независимое read-only ревью не нашло Important/Critical дефектов; форматирование перепроверено.
